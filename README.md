Harmoody — Música para o que você quer sentir

Uma aplicação web que conecta música, emoções e personalização para criar experiências musicais alinhadas ao estado emocional desejado.
O projeto explora a relação entre música, emoções e tecnologia, propondo uma forma de recomendação musical que considera não apenas os gostos do usuário, mas também a experiência emocional que ele deseja alcançar.
